先講實話：3個月背完3000個「一個一個記」的單字不切實際。補習班真正的做法是兩層—— 約1200個高頻核心字硬背，另外約2000字靠字根規則批量解鎖。 英文的 -tion 對應西語 -ción，你會 nation 就自動會 nación。 這種規則只有15條，但一次打開好幾千字的辨識能力——這是你英文底子最值錢的地方。

每天投入抓 60–90 分鐘，照下面12週走。每週固定：文法1個主題 + 字彙2個主題 + 動詞5個 + 字根1條規則。
好消息：西班牙文是「看字讀音」的語言，字母跟發音幾乎一對一，沒有英文那種 through / though / tough 的鬼故事。這一頁看完，你就能唸出任何沒看過的西班牙文字。
這是整個課程投報率最高的一頁。英文有大量詞彙來自拉丁文，西班牙文也是—— 兩邊等於是遠房表兄弟。下面每條規則都是一把鑰匙，記一條規則＝解鎖幾百個字。

但要小心「假朋友」（false friends）：長得像卻意思完全不同的字， 最後一段特別列出來，這些是考試和實戰最常出糗的地方。
核心字彙庫，按主題分類。藍色 el = 陽性、粉色 la = 陰性， 綠色是形容詞、橘色是動詞。勾選記錄學習進度（存在本機瀏覽器）。 標橘字的是與英文同源、幾乎白送的字；標紅字的是陷阱字，要特別留意。

童謠是初學者最被低估的工具：重複、押韻、句型固定，唱一遍等於把同個結構輸入好幾次。 下面四首是為這套課程原創撰寫的歌詞（不是現成童謠的翻譯）， 用字全部對齊你的字彙表，可以直接套熟悉的旋律唱。

每句都能點著聽，也附逐字拆解。建議唱出聲——默念練不到發音肌肉。
每一條都用英文對照來解釋——你已經會的英文文法就是最好的鷹架。 按12週的順序排列，第1週看第1組就好，不要一次全吞。
西班牙文動詞會依六個人稱變化，這是英文使用者最大的門檻，也是唯一沒有捷徑的部分。 好消息是：規則動詞只要記三組字尾（-ar / -er / -ir），套進去就通用。 先把標不規則的那些吃掉，它們同時也是最常用的。

每個變化形都可以點下去聽發音，下方例句附中文翻譯、整句朗讀，還可以展開逐字拆解——每個字的文法角色和意思都標出來。
實戰短句，按情境分類。文法還沒學到也沒關係——整句先背起來當公式。

每句都給兩個版本：藍色「標準」是教科書寫法，文法完整、任何場合都不會失禮； 橘色「口語」是母語者日常真的會講的，比較短、常省略主詞。 下面附一句放進對話裡的例句，可以展開逐字拆解。
